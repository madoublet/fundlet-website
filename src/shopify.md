Fundlet for Shopify turns your Shopify store into a fundraising platform. Run a campaign, track who's selling what, and get paid through the Shopify store you already use.

The app, the tutorial library, and the setup guides all live on this page.

---

## Open the Shopify app

Install Fundlet from the Shopify App Store, then open it any time from **Apps → Fundlet** in your Shopify admin to manage campaigns, participants, and payouts.

<p><a class="btn btn-primary" href="https://apps.shopify.com/fundlet">Add to Shopify Store</a></p>

Fundlet installs like any other Shopify app — no theme code to edit and nothing to host yourself.
